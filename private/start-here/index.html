使用说明

Jan 1, 0001

本页用于说明 团队共享 栏目的使用方式，建议后续优先完善此页，作为团队成员进入专区后的第一站。

页面定位

  • 说明本专区服务对象是谁
  • 说明本专区适合放什么内容
  • 说明哪些内容不应直接放在网站页面中

建议组织方式

  • 按“教程 / 资料 / 工具 / 笔记 / 规范”进行分类
  • 每个页面尽量只处理一类主题，便于后期持续扩展
  • 对于下载类材料，建议提供简介、适用对象、更新时间和来源说明

建议维护规范

  • 每次新增资料时补充标题、简介、更新时间
  • 对外链资料注明来源与访问方式
  • 对于失效资源及时替换或标注停用
  • 对于仍在整理中的页面，可在顶部标明“更新中”

后续待补充

  • 团队共享专区的适用范围说明
  • 团队成员维护分工
  • 内容更新频率与约定
  • 资料命名规则
